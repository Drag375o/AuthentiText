# Screenshots

The README references these files by name. Drop a PNG with the matching name into
this folder and it appears in the README automatically; no other change is needed.

| File | Where to capture it | What should be on screen |
|---|---|---|
| `landing.png` | `/` | the hero, with the sample document card and the reading-lens background |
| `login.png` | `/accounts/login/` | the split sign-in page, including your `hero.webp` panel |
| `dashboard.png` | `/dashboard/` | the activity chart, the counts, latest analysis and the "needs attention" list |
| `analyze.png` | `/analyze/` | the editor with text in it, so the live counts and evidence gauge are filled |
| `results.png` | `/analysis/<id>/` | the top of a result: demo notice, signal, confidence, uncertainty |
| `heatmap.png` | `/analysis/<id>/`, scrolled to **Sentence heatmap** | marked sentences with the explanation panel |
| `rhythm.png` | `/analysis/<id>/`, scrolled to **Sentence rhythm** | the bar chart and the length statistics |
| `patterns.png` | `/analysis/<id>/`, scrolled to **Pattern explorer** | matched phrases shown in context |
| `profile.png` | `/profile/`, scrolled to **Across your documents** | the dot tracks, ideally with three or more documents |
| `compare.png` | `/compare/?a=…&b=…`, scrolled to **What changed** | the side-by-side diff with struck-through and underlined wording |

**Capturing them.** A browser window about 1280 px wide matches the current files.
Use a full-page screenshot only if you want the whole page; the versions here are
single screens, which read better in the README.

**A note on content.** These screenshots show whatever documents are in your
account, so use text you are happy to publish.
