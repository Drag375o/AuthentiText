AboutAuthentiText

AuthentiText is an NLP-powered writing analysis platform that combines linguistic analysis, stylometry, statistical text features, semantic similarity, and machine learning to provide explainable document-level and sentence-level writing analysis.

It is a portfolio project. It makes no claim to research-grade accuracy, and every number it shows is traceable to a feature you can inspect.

The pipeline

  1. Text extraction
  2. Preprocessing
  3. Linguistic analysis
  4. Lexical features
  5. Syntactic features
  6. Statistical features
  7. Semantic features
  8. Stylometric features
  9. ML classification
  10. Explainability
  11. Visual analytics
